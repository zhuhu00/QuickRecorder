# 1.8.7 录制与转写更新

2026-11-02。此记录描述最终实现；版本号 1.8.7（187）。

## 声音来源

- 主界面独立控制系统声音和麦克风，普通录屏与快捷录屏遵循同一个设置。
- 纯录音支持系统声音、麦克风单独录制或两者混合；两项均关闭时阻止开始录音，录屏允许无声输出。
- 麦克风单独录音使用单一音频文件，由首个麦克风样本启动写入时间轴；双来源继续使用既有 QMA 混音流程。

## 转写

- 录音 M4A/MP3 与录屏 MP4/MOV 均输出同名 TXT/SRT，保留重名避让及成对写出。
- 自动转写入队前流式读取各音轨。没有音轨、空音轨或全部解码块的 RMS 不超过 -60 dBFS 时跳过，不生成字幕和文本，也不弹出转写通知。
- 检查覆盖完整录制，发现声音即可结束扫描；多声道不先混为单声道，避免反相抵消造成误判。
- 文件读取失败沿用既有队列错误处理，不当作静音；声音活动检测也提前到 Whisper 模型加载前。能量检测只区分有声与基本静音，不等于识别人声。

## 控件与窗口

- 右侧两行布局：左列 Cursor / 系统声音，右列摄像头 / 麦克风，设置与关闭上下排列。
- 摄像头和麦克风保留当前设备名称；点击显示完整设备列表，不使用滚动菜单或二级菜单。
- 主工具栏第一列收窄；菜单栏弹窗下方控件与上方录制入口等宽对齐。
- 主工具栏空白区和摄像头画面的拖动由窗口事件层处理，避开控件、翻转按钮与缩放边缘。
